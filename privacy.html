Privacy

Last updated: October 25, 2026

What we collect

Nothing. The calculators run entirely in your web browser. The values you type are not sent to us, stored on our side or saved on your device. We don't use cookies, analytics, advertising or tracking scripts, and we don't ask for any personal information.

Hosting

This site is hosted on GitHub Pages. Like any web host, GitHub may log technical information such as your IP address when your browser requests a page. We don't receive or control those logs. See GitHub's privacy statement for details.

Changes

If this ever changes (for example if we add analytics or accounts), we'll update this page first and say what changed.

Questions

Open an issue on the project's GitHub page.
