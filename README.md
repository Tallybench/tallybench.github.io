# Tallybench

Free, private, in-browser calculators for small business owners. Static site, no build step, no tracking, no cookies.

Live site: https://tallybench.github.io/

- `index.html` – home
- `markup-margin-calculator.html` + `markup-margin.js` – tool #1
- `privacy.html`, `terms.html`, `about.html` – legal and info pages
- `tests/test-calc.js` – maths sanity tests (`node tests/test-calc.js`)

Deployed with GitHub Pages from the root of the `main` branch.
